# LeakLock – Personal Information Leak Detector

## About the Project
LeakLock is a Python-based application designed to detect sensitive personal information in text and documents.

## Features
- Email Detection
- Phone Number Detection
- Aadhaar Number Detection
- Sensitive Information Masking

## Technologies Used
- Python
- Streamlit
- Regular Expressions (Regex)

## How to Run

1. Install the required libraries:
   pip install -r requirements.txt

2. Run the application:
   streamlit run main.py
